# What this tool says about its own bill of materials

A checker whose own bill of materials has never been checked is selling something it has not tried. This is that, generated by command and regenerated by `verify.sh` on every build.

## The document

| | |
|---|---|
| Generated by | `syft` |
| Format | CycloneDX 1.7 |
| Components | 85 |
| Checked against | `cisa-2026-v2.1` |
| Findings | **266** |

**Almost every component is a development dependency**, mostly platform binaries that Next.js pulls in for image handling. The engine declares zero runtime dependencies and a CI step enforces it. Quoting the component count without saying that would overstate the surface.

## Whose fault this is, stated fairly

Not the generator's. syft is a good tool and produced several of the files in `fixtures/corpus`. A pnpm lockfile records names, versions and integrity hashes so that installs resolve; it does not record a producer or a licence for each package. A generator reading a lockfile cannot emit what the lockfile does not contain.

That is the finding, and it is about the ecosystem rather than about one tool. The default output of a standard generator, run the standard way on a real project, does not meet the CISA minimum elements. The corpus says the same thing across 21 files from other projects; this says it about us.

## The number that is not zero, and the one that is

There are **266 findings** and **0 at severity error**. Those are consistent: `cisa-2026-v2.1` contains no rule at severity error, because the CISA minimum elements document is not a regulation and no rule citing it should read as a filing blocker. `--fail-on error` would exit 0 on this document, which is correct and is exactly the kind of thing a reader should be told rather than left to discover.

## Reproducing this

```
python3 scripts/self-sbom.py --generate /path/to/syft
```

The document is committed at `docs/self/stratifypro.cdx.json` and the result at `docs/self/self-check.json`. `verify.sh` re-runs the engine over the committed document and fails if the result has moved, so this page cannot drift from what the tool actually says.
